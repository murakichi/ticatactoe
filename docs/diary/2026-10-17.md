# 2026-10-17

## シャッフルで手札を引き直す行動パターン（軍師・あなたに採用）
- 発想: 今のAIは手札（ランダム3枠）を引き直さない。トークン系が手札に無いまま魔力を溜めて眠らせるのは無駄では、と
  「トークン系が手札に無く、トークンを撃てる魔力（1+4）が残るときだけ、シャッフル（魔力1）を1回」を試した
- 計測（自キャラ vs 他7キャラ、先後、各約840試合、SE約±1.7pt）。そのキャラだけに適用して比較:

| キャラ | seed 3 | seed 4 | seed 5 | 判断 |
|---|---|---|---|---|
| 軍師 | +3.9 | +2.7 | +2.1 | **採用**（トークンが戦力の源） |
| あなた | +1.1 | +0.7 | +0.9 | **採用**（固有スキルが無く手札運が全て。効果は小さいが全 seed で同方向） |
| 巨人 | -1.5 | - | - | 対象外 |
| 魔法使い | -1.4 | - | - | 対象外 |
| 陰陽師 | -4.1 | - | - | 対象外 |
| ネクロ | -4.8 | - | - | 対象外 |
| 毒使い | -0.3 | - | - | 対象外 |
| 雷霆の巫 | -0.7 | - | - | 対象外 |

- 2回まで引き直す版（軍師 +4.0、あなた +1.2）は1回と同じなので、単純な1回にした
- 本番の実装: ゲームのAI起動は手番が変わったときだけで、シャッフルの後にAIをもう一度呼ぶ形にできない。
  `runAIMove` の中で、判断の前に手札を引き直し、新しい手札と魔力でそのまま `makeMove` に渡す（sim と同じ順序）。
  `AIPlayer.shouldShuffle`（軍師と「あなた」だけ）が判定する。型チェック・画面確認は未実施
- 教訓: 行動パターンの効果はキャラの特性（何が戦力の源か）に強く依存する。全キャラに一律に入れると悪化するものがある
