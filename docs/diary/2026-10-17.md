## 毒霧（全コマに毒を撒く汎用スキル）を追加

### やったこと
- 「敵味方問わずすべてのマスに毒を与えるスキル」を汎用プール idx 29 に追加（名前は仮で「毒霧」）。
  盤上の全コマ（敵味方問わず）に毒を1付与。🔑ロック・無敵は対象外。空きマスには付けない。対象選択なし。
  コスト8（毒系なので毒使いは7）。`skillCosts.ts` / `Game.tsx` / `sim/engine.js` / `sim/ai.js` / `AIPlayer.ts` / `skillMeta.ts`、プール 29→30

### なぜ / 判断
- 既存のパンデミックは「選んだ3x3」。全盤版は対象選択が要らず、1手で盤全体の毒が+1される別物として足した
- コスト8は猛毒化（8）に合わせた推測。**人間が握った感触では未調整**
- 毒使いは自コマに毒が付くとライフ1.5倍になるので、全盤に撒くと自コマは耐え、敵コマだけ削れる。AIは『敵コマが自コマより2つ以上多く、敵4つ以上』のときだけ撃つ

### 計測
12試合×3 seed（8キャラ総当たり）、毒使いの勝率: master 0.514 / 0.555 / 0.548 → 毒霧あり 0.525 / 0.503 / 0.589（平均 0.539 → 0.539、変化なし）。他キャラは全て seed のぶれの範囲（±5pt）。

- **AIはほぼ撃たない**: 毒使いAIが毒霧を手札に持った44手番のうち、払えたのは3、撃つ条件を満たしたのは0（敵2以上・差0まで緩めても0回/450試合）。
  毒使いは魔力が常に足りず、撃つ前に他のスキルで使い切る。つまり上の『勝率が変わらない』はAIが撃たないせいで、スキル自体の強さの測定にはなっていない
- 手札に来る確率は3/30＝10%/手番。プールが29→30になった希釈は計測上無視できる
