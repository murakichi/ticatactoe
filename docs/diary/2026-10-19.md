# 2026-10-19

## AIのギア活用: 連鎖割引・四連の極意に合わせた打ち方は2案とも無効（#58）
- 背景: #58 の測定で、連鎖割引・四連の極意は対照群と差が出なかった（0.503 / 0.501 vs 0.501）。AI がギアを活かす打ち方をしていないのが主因と見て、AI 側から試した。
- 試した案と結果（`probe-gear.js 1500 <seed>`、装備側の勝率、標準誤差 約±1.3pt）:

| 案 | seed 1（連鎖割引 / 四連） | seed 2 |
|---|---|---|
| 現状（master） | 0.517 / 0.515 | 0.500 / 0.500 |
| スキル計画を実コスト（計画に積んだ数ぶん割引・4つ目無料）で見積もる | 0.517 / 0.515 | 0.500 / 0.500 |
| 上記＋バッズを積極的に撃つ（空き3以上・バッズ5未満） | 0.518 / 0.516 | 0.498 / 0.498 |

- **平均ターンまで小数一致**（14.6）。割引が効く局面がほぼ発生していない。両案とも却下、コードは撤去。
- 原因の見立て（未検証）: 手札は29枚中3枚で、AI が1手番に撃つスキルは多くて1つ。2つ以上撃たないと連鎖割引・四連の極意は発動しない。
  手札依存のため、撃つ条件を緩めても2つ目が手札に来ない。ギアの設計側（条件を緩める・手札に依らない）の話と判断。
- 測っていない: 収穫・伝播・道連れの鍵・増援・軽量トークンへの AI 対応、AI が自分のキャラに合うギアを選ぶ案（`probe-gear` では価格破壊 0.613・剛腕の代償 0.593 が強い）。
