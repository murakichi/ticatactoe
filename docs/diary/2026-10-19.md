## AIのギア活用: 連鎖割引・四連の極意に合わせた打ち方は2案とも無効（#58）
- 背景: #58 の測定で、連鎖割引・四連の極意は対照群と差が出なかった（0.503 / 0.501 vs 0.501）。AI がギアを活かす打ち方をしていないのが主因と見て、AI 側から試した。
- 試した案と結果（`probe-gear.js 1500 <seed>`、装備側の勝率、標準誤差 約±1.3pt）:

| 案 | seed 1（連鎖割引 / 四連） | seed 2 |
|---|---|---|
| 現状（master） | 0.517 / 0.515 | 0.500 / 0.500 |
| スキル計画を実コスト（計画に積んだ数ぶん割引・4つ目無料）で見積もる | 0.517 / 0.515 | 0.500 / 0.500 |
| 上記＋バッズを積極的に撃つ（空き3以上・バッズ5未満） | 0.518 / 0.516 | 0.498 / 0.498 |

- **平均ターンまで小数一致**（14.6）。割引が効く局面がほぼ発生していない。両案とも却下、コードは撤去。
- 原因の見立て（未検証）: 手札は29枚中3枚で、AI が1手番に撃つスキルは多くて1つ。2つ以上撃たないと連鎖割引・四連の極意は発動しない。
  手札依存のため、撃つ条件を緩めても2つ目が手札に来ない。ギアの設計側（条件を緩める・手札に依らない）の話と判断。
- 測っていない: 収穫・伝播・道連れの鍵・増援・軽量トークンへの AI 対応、AI が自分のキャラに合うギアを選ぶ案（`probe-gear` では価格破壊 0.613・剛腕の代償 0.593 が強い）。

### 氷結の仕様変更と氷室の番人のパッシブ確定（ユーザー指示）
- 氷結を**スタック化**（スキルダメージは1スタックずつ肩代わり）。付いた時点で🌱が消え、🔑も掛けられない。
- 氷室の番人: ライフ平均+1、自陣の❄総数×0.5加算、ライフが残る敵の氷結マスを押すと解除。固有スキルは**保留**（氷河期は仮のまま）。
  旧パッシブ（氷結中の自陣に重ねて強化できる）は仕様に無いので**廃止**した。
- 解釈した点（要確認）: 「氷結状態の数」は自陣コマの❄**スタック総数**／解除は**全スタック**／解除クリックは**手番を使う**（無料にすると敵の氷結を毎手番ただで剥がせるため）／
  発火による解除は全スタック。AIは解除クリックを使わない。

### 氷結の空きマス対応と氷室の番人の確定（ユーザー指示）
- 「自由に剥がすのは無し」で解除クリックを廃止。氷結は空きマスにも置け、氷結中の空きマスはロック同様に着手不可。
- 氷室の番人: 常在ロック→氷結(コスト2)に置換。固有スキルは**絶対零度**（コスト10−氷結マス数、全マス❄+1、次の自手番開始に敵の❄×3ダメージ・氷結解除・ライフ0は破壊）。スキル名は仮（指定なし）。
- 判断: 全マス凍結の後に空きマスの❄が残ると**試合が止まる**（ブラウザ版テストで発覚: 氷結後はその手番に誰も置けない）ので、発動時に**空きマスの❄も解除**。
  打開はスキル、何もできなければチャージで終了（既存のパス経路で、sim の氷室の番人同士/対鍛冶師/対巨人 各200試合で停止0）。
- 「ターンに一度」: 発動待ちの間は再使用不可（`glacierPending`）。次の自手番開始で解けるので、1手番に1回まで。
- 未計測: 絶対零度・氷結のバランス（強さ、AIの撃ち方の妥当性）。→ issue #73

### 汎用スキル「浄化」（ユーザー指示）
- 自陣の全状態異常を回復する汎用スキル。idx32、コスト5（血清4より少し上、未計測）、プール33種。
- 判断: 「状態異常」＝☠毒・🔥火炎・❄氷結・⚡帯電（全スタック）。🌱🔑は残す。⚡は雷霆の巫の無敵の源でもあるので、雷霆の巫のsim-AIは撃たない。
- 未計測: 強さ・AIの撃ち方（自陣の状態異常3スタック以上で撃つ）。→ issue #73

### 火炎と氷結の相互作用、煉獄の鍛冶師の確定（ユーザー指示）
- 氷結中のマスに🔥を付けようとすると、🔥の代わりに❄が1スタック減る（🔥は付かない）。🔥が実際に付いたときだけ縦横隣の氷結が全解除。
- 煉獄の鍛冶師: パッシブは「敵が火炎ダメージを受ける時、追加で1ダメージ」（旧「自陣の🔥は無効」は廃止＝私が仮置きしたもの）。固有スキルは「敵マス全てに火炎+2」で、旧フレアバーストを置換。
- 解釈（要確認）: 「火炎ダメージ」＝ターン進行の継続ダメージ（1マスの1回につき+1。スキルの1.5倍は別）／鍛冶師が複数いても+1／敵マス全て＝使用者以外のコマ全て（🔑中・⚡無敵は除く）／スキル名「業火」とコスト9は仮（未指定）／
  氷結マスに+2すると氷結が先に減り余りが🔥になる（氷結1つなら1つ目で氷結消滅→2つ目が🔥）。
- 未計測: 業火・鍛冶師の強さ。AIは敵コマ(ライフ>0)3個以上で撃つ。→ issue #73

### バッズ系の汎用スキル4種（ユーザー指示、名前もユーザー選択）
- 背景: 氷結・火炎が🌱を消すようになり、バッズ経済が弱くなった。案から1〜4を採用し、名前は刈り入れ前夜／冬至の種子／ひこばえ／風の落とし子。idx33〜36、プール37種、コストは 2/4/3/3。
- 判断: 冬至の種子の「🌱ガード」は、freeze/freezeAll/ignite の `keepBuds` 述語で実装（呼び出し側が席のガード状態を渡す）。解除は**その席の次の手番開始時**。
  氷結・火炎中のコマには🌱を足さない（足してもすぐ消える環境のため。`canBud`）。
- **バランス懸念（未計測）**: 風の落とし子は 3コスト→🌱3個で、既存のバッズ(4で1個)・ダブルバッズ(6で2個)よりかなり割安。魔法使いと組むと強すぎる恐れ。コスト引き上げ（6あたり）を計測で確認したい。→ issue #73
- AI: 刈り入れ前夜と冬至の種子は、他席に氷室の番人/煉獄の鍛冶師がいるときだけ使う（刈り入れは魔法使い以外）。ひこばえは受け手2つ以上、風の落とし子は自陣🌱3未満かつコマ3個以上で使う。

### ひこばえの調整（ユーザー指摘）
- 「確定で全部に付くなら軽すぎる」。縦横隣が4つあれば🌱4個がコスト3で確定し、風の落とし子（3で3個ランダム）より得になるため。
- 採用: **付くのは最大2つ（隣が3つ以上ならランダムに2つ）＋コスト3→4**。バッズ(4で1個)とダブルバッズ(6で2個)の間に収まる。未計測。

- 追加した演出（バナー＋エフェクト＋専用の効果音）: 絶対零度の使用(glacier)・発動(glacierBurst)、業火(inferno)、浄化、刈り入れ前夜、冬至の種子、ひこばえ、風の落とし子。氷結(freeze)/火炎(flame)は既存。

### AI戦略への取り込み（ai-improve、paired A/B）
- Phase 1（正しさ・A/B不要）: 着手不能な4つ目しか残らないラインをリーチと数えない／氷結中の敵をスキルの「効く敵」に数えない／氷結中のコマとその⚡を帯電系の対象にしない。
  絶対零度後や氷結空きマスだらけの盤でも、着手候補が空ならチャージでパスして停止しない（2〜6人戦236試合で停止0）。同キャラミラー 49〜51% で退化なし。
- Phase 2（同一seed・n=300〜400、±は95%区間）:
  - **採用** B: 氷室の番人が相手の単独リーチを氷結（ロック置換、コスト2）で塞ぎ、着手は攻めに使う。氷室 vs あなた 57.8→69.5%(+11.7±6.6)、vs 巨人 +34.5 ほか多数が有意。
  - 却下: B の全キャラ版（汎用氷結 idx30、手札依存で+0〜1）／A 評価関数の❄🔥項（AI同士ではほぼ発生せず差0.0）／C 火炎付与（+0〜0.7）／F 脅威なしの先行氷結（vs あなた −11.8±6.4）。
  - 変更なし: D 絶対零度・業火の閾値（撃たれる頻度が0.03/0.06回/試合で測定不能）。
  - E 使用率（1試合あたり）: 風の落とし子0.11〜0.17、ひこばえ0〜0.23、冬至の種子・刈り入れ前夜・浄化ほぼ0。風の落とし子の魔法使いミラー(n=1600)は「毎回撃つ」+3.1±3.5＝強すぎる兆候なし。
- **氷室の番人がAIだと強すぎる**: 今回の採用で vs あなた の勝率が 21〜29%（あなた側）。バランス調整の要否を要検討。→ issue #73
