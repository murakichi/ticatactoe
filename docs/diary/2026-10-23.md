## 盤面まわり（モバイルで画面スクロールなし／スキル欄の横スクロールを分かりやすく）
### やったこと
- モバイル（幅720px以下）は、通常は1画面に収める表示にした。上から プレイヤー（横長に圧縮）→ 手番 → 盤面 → 操作ボタン → スキル（横一列）→ 最新ログ1行。盤面の大きさは、盤面の領域の残り高さ（container query の `cqh`）から手番表示と操作ボタンの分を引いて決める。ギア・固有スキルのコスト・状態・ログ全文・スキルの説明は「詳細」ボタンで出す（従来の縦長の表示）。確認は幅360〜390px・高さ640〜844px、2人と6人で、ページの高さが画面の高さと一致（スクロールなし）
- スキルカードが、狭い画面で縦に積まれていたのを直した。原因は「狭い画面では折り返す」指定が残っていて、幅180pxのカードが1枚ずつ縦に並んでいたこと。全画面幅で横一列にした
- 横に続くことを見落とさないよう、はみ出す側にだけ「‹ ›」ボタンと端のフェードを出す（押すと160pxずつ動く）

### なぜ / 判断
- 以前「折り返す」にしたのは、横スクロールだと右の手札が見つからなかったため。今回は逆に、縦に積むと手札の数も続きも分からなくなる、という指摘。折り返すのをやめ、「続きがある」ことを見せる方向で解決した
- 盤面を小さくしすぎないため、スキルの説明（アコーディオン）はモバイルの通常表示では隠した。説明は「詳細」で読める
- 以前のテスト（狭い画面では折り返す）は、この判断の逆なので「折り返さない」に書き換えた

### 計測
- tsc エラーなし、jest 全件パス（矢印の出る/出ない・スクロール・「詳細」の切替のテストを追加）
- 実機のスマホ（iOS Safari のアドレスバーで 100dvh が変わる場合、`cqh` 非対応の古い端末）は未確認

## AIの手番中に人間が触れてしまうバグ
- 原因: AIは人間と同じ `onCellClick` と各スキルの関数を直接呼んで動く作りで、画面側（盤面のクリック・スキルカード・ロック切替・つらら（icicle）の向き選択）に「いまAIの手番か」の判定が無かった。AIが考えている間に人間が押すと、AIの席の手として盤面やスキルが実行されていた（手番を飛ばすチャージも押せた）
- 修正: `aiTurn`（手番の席がAIで、勝負が付いていない）の間は、盤面のクリックとホバープレビュー、スキルカードとロック切替、icicle の向きボタンを受け付けない。AI自身は画面のボタンを経由せず直接関数を呼ぶので影響しない。スキルカードは押せない見た目（グレー）になる
- 測定: 盤面のガードを外す変異で、追加テスト（`Game.aiTurn.test.tsx`）が落ちることを確認。jest 全件パス
- 積み残し: なし（全員AIの対戦で人間が盤面に触れる経路も、同じガードで塞がる）

## 陰陽師のナーフと、sim/本番のずれの是正（#178）

### やったこと
- 式神一括を『固定6』→『式神1体につき3』に（`sim/engine.js` / `skillCosts.ts`）。百鬼夜行は一度『ランダム3マス』にしたが、ユーザーの意向で全マスに戻した
- sim と本番AIの勝率のずれ（13〜30% / 76〜90%）の原因を3つ特定して是正（`sim/ai.js`、`Game.tsx executeSkillForAI`）
- 計測テスト `aiMatch.probe.test.tsx` にトレース（`AI_MATCH_TRACE=all`）、使用スキル集計（`AI_MATCH_USAGE`）、陰陽師のギア/デッキ指定（`AI_MATCH_HGEARS` / `AI_MATCH_HDECK`）を追加

### なぜ / 判断
- コストだけのナーフ（一括2）は sim では 57% まで落ちたが、本番では約91%のまま、と報告した。**この『本番91.6%』は集計ミスではなく、当時は本番AIが本当に強かった**（陰陽転化が実行されないバグで、陰のまま爆破できていたため）。一方、その後の『本番49〜53%』は**集計ミス**（`💙の勝利` を数えていて、後手の試合で相手の勝ちを数え、5割に寄っていた）。本番の正しい数字は `yinYang wins X/Y`
- ずれの原因を探すのに効いたのは、決定ごとの魔力の推移を並べたこと。sim だけ1手番あたり約2少なく、(a) sim の陰陽師が余り魔力の引き直しで魔力を捨てる、(b) sim の陰陽師が陽に居座る（本番AIは陰陽転化が何も起きず常に陰）、が見つかった。(c) `yyCover` が sim では全キャラに掛かっていた
- (b) は『本番が正解』ではなく本番のバグだったので、sim を本番に寄せず本番を直した
- 陰陽師の強さは『環境の上位ならok』（ユーザー判断）。一括3 + 百鬼夜行全マスで据え置き

### 計測
- 是正後、式神一括3 + 百鬼夜行全マス: sim 50.1%（seed3 / 300試合、推奨ギア・入れ替えデッキ）、本番AI 205/349 = 58.7%（各40戦×9相手）
- 対キャラ別は概ね一致。外れ値: 対軍師 sim 19 / 本番 50、対毒使い 32 / 71、対ネクロ 30 / 16（n=40 の誤差±8を超える）
