# スキルのコスト基準

新しいスキルを作る・コストを変えるときは、**必ずこの基準で値を出す**。
基準から外すときは、外した理由を作業日記に書く。数値の唯一の出典は
`src/components/game/skillCosts.ts`（sim は `sim/engine.js` の `skillCosts` と `sim/config.js` が同値）。

## 基本単価

| 区分 | 値 |
|---|---|
| トークン（ランダムな空きマスに自陣コマを置く） | **4** |
| エフェクト1個の付与 | 🔑・⚡・☠ **2** ／ ❄・🔥 **3** ／ 🌱 **4** ／ 🍂 **約2** |
| 敵コマ1つの破壊 | **4〜5**（付随効果は上の単価を足す） |
| 手番を終えるスキル | **−2〜−3** |

## ルール

**R1 自陣に不利な条件があるトークンは −1。** 帯電/氷結/火炎トークン 3、両トークン 3、ポイズントークン 2、式神ランダム 2。

**R1' 自傷エフェクトは割安にする。** ☠・🔥・⚡（雷霆の巫以外は乗った時点でダメージ）のように、自陣のコマに乗ると自分が損をするエフェクト（キャラやギアで活用しない限り）を付与するスキルは、無害な同構造のスキルより **−1**。敵だけを選んで付けるスキル（毒注入・火炎付与など）は自傷しないので対象外。❄は自陣に乗せても守りになるので対象外。単価は割引後の値でR3の式に入れる（二重に割り引かない）。
- 例: 落葉の衣 3（ランダムな自陣のコマ1つに🍂。🍂の単価約2＋ランダム選択のぶん。ユーザー指示で3）、枯野の相席 5（敵味方の全コマに🍂）、木枯らしの使い 5（基準の5〜6。以前は凩の魔女の🍂供給が律速のためユーザー指示で3にしていたが、ユーザー指示で5に戻した。2026-10-30）、落ち葉の置き土産 1（敵のコマに🍂を付けると持ち主以外=自分のコストが上がるので、🍂の単価約2から −1）、焚きつけ 5（敵の🍂を🔥に変換）、帯電/火炎トークン 3、ポイズントークン 2、毒霧 6（敵味方を問わず全コマに☠）、静電気の季節 7・総毛立つ 6（⚡は自陣のコマに乗る）。

**R2 トークンに有利な効果を足したら、その効果の単価を足す。** バッズトークン 6（4+2）、🍂付きトークン 5〜6。

**R3 複数付与は個数が増えるほど1個あたりが安く、式以下にする。**

> n個付与の価格 ≒ 単価 × n × 0.85^(n−1)（四捨五入）。この値**以下**にするのは構わないが、これより高くしない。

| 単価 | n=2 | n=3 |
|---|---|---|
| 2（🔑・⚡・☠） | 3 | 4 |
| 3（❄・🔥・トークン+効果） | 5 | 7 |
| 4（🌱・素のトークン） | 7 | 9 |

**R4 範囲・全体系は対象数が多いほど、絶対額は上がっても1個あたりは下がる。**
目安: ランダム 3 ／ 3×3 約 5 ／ 直線 6 ／ 連結 7 ／ 盤面全体 7〜9。

**R5 軽減系は、節約できる最大値より必ず安くする。** 節約額が自分の条件で伸びるなら上限を付ける。

**R6 固有スキルは汎用より1〜2割増しの価値を持たせてよい。** ただし、汎用に同効果があれば汎用の価格を下回らない。

**R7 派手さと導線（条件付き軽減）。**
- 広範囲・多数付与・大量破壊のスキルは、**条件なしならベースを重く**する。
- 成立させるのに工夫が要る条件（導線）があれば、**最大 −2** まで軽くしてよい。
- 導線は次の3種類のどれかにする。
  - **コンボ型**: 別のスキルで条件を作る（例: 火炎を付与すると火の車が0になる）。
  - **カウント型**: 盤面の個数で安くなる（例: 帯電付与は⚡の数、絶対零度は❄の数、ミアズマは毒の数、一寸先は闇鍋は盤面のエフェクトの数、雷を食らわば皿まではこの手番に付与した⚡の数、一寸の虫に魂なしは盤面のコマの数。軽減の下限は1）。
  - **ループ型**: 使うと条件がリセットされ、次のサイクルを回す工夫が要る（例: 自陣の⚡が0なら静電気の季節が安い）。
- 逆に、**条件なしで派手なのに軽い**スキルは基準違反として値上げか導線追加を行う。
- 条件の判定は `gearCost`（`Game.tsx` と `sim/engine.js`）に集める。ボタンの「使えるか」判定にもスキル名を渡して、軽減後のコストで判定する。

## コストの計算順（増加分 → 減少分）

実コストは、**増加分を先に足し、減少分をそのあとに引く**。実装は `Game.tsx` の `characterCost` → `gearCost`（`sim/engine.js` も同じ）。
1. 基礎コスト（スキルごと、価格破壊で席ごとに変わりうる）
2. 増加分: 敵の🍂の枚数、キャラの加算（軍師の非トークン+2、毒使いの毒以外+1、陰陽師の陽+1）
3. キャラの減少分: 軍師のトークン-1、毒使いの毒系-1、煉獄の鍛冶師の🔥付与-1、凩の魔女の盤面の🍂ぶん
4. ギアの補正と割引スキル、導線（コンボ）の軽減

減少のたびに下限1（もともと1以下のコストは変えない）。増加分を最後に足すと、割引や下限1に守られずに増えるので、**必ず増加分が先**。

## 作成時のチェックリスト

1. 効果を「単価 × 個数」に分解して、R1〜R4 で基準値を出す。
2. 派手なら R7 で導線を設計する（導線がないなら基準値のまま重くする）。
3. 近い既存スキルと並べて、**常に上位互換になっていないか**確認する（例: トークン 4 より安いのにトークン以上の効果がある、は不可）。
4. 値は `skillCosts.ts` と `sim/engine.js`（と必要なら `sim/config.js`）に同値で書く。キーの順序も揃える。
5. 強さは `sim/probe-cost.js` で測り、作業日記に数字を残す。未測定なら issue に起票する。

```bash
node sim/probe-cost.js --skill <idx> --name <SKILLSのキー> --char <キャラ> --opp giant --games 200 --seed 1
```

## 現行の基準からの外れ（意図的）

| スキル | 値 | 理由 |
|---|---|---|
| バーンアウト 5 | 🔥が4つ以上で0 | カウント型の導線 |
| 火の車 5 | 敵か自陣に🔥を付与していれば0 | コンボ型+ループ型の導線 |
| 春一番 2 | 解除した❄の数だけこのターンのスキルを軽減 | 霜枯れで❄を作る導線。R5 の上限は要計測 |
| 式神割引 2 | 次のスキルを 2＋式神の数 だけ軽減 | 式神を並べる導線。軽減量は盤面の式神(敵のも)で決まる |
| 式神の供犠 5 | 自陣の式神が3体以上で0 | 式神を並べる導線(カウント型)。ランダムに1体壊すので連打は式神を3体に戻す手間がかかる |
| 雷神のへそくり 1 | 除去した⚡1つにつき次のスキル −1 | ⚡を溜める導線。無敵⚡を失う代償がある |

### 飛び火（idx 97, 基礎 4）の算出
- 効果: ランダムな敵コマ2つに🔥を1つずつ（付与の瞬間に1ダメージ）。火の車からシャッフルを除いたもの。
- 単価: 🔥 3。R3（n=2）: 3×2×0.85 ≒ 5 が上限。
- ランダム選択（狙いを選べない）で **−1 → 4**。火の車（5。シャッフル付き）より安いが、効果もシャッフル分だけ小さい（上位互換にならない）。火遁（3, 1つを選ぶ）の2回分（6）より安い。
- 導線: 『直前の手番に相手がコマを2つ以上設置していれば、各ターン1回まで0』（コンボ型ではなく相手の行動待ちの条件。R7 の −2 を基礎に織り込まず、無料はカウント外の追加の旨み）。コマを置くスキルを相手が使った手番の直後だけ無料なので、連続で無料にはならない。
- 鍛冶師は🔥付与で −1（実コスト 3）。
| 柳の下に二匹目がいた 6 | この手番に基礎コスト7以上のスキルを使っていれば0 | コンボ型の導線。大技のあとに追撃のランダム発動(基礎5以下)が無料で付く。デッキのスキルを使うので福引き(2)より重い |
| 超助っ人 3 | なし | 素のトークン4 −1。☠🔥⚡が出ると自傷し、🌱❄🍂は当たり外れがあるランダム付与。トークンなのでターン1回 |
| パーフェクトゲーム 10 | なし(軽減なし) | 盤面全体の大量破壊(敵味方とも)。R7の『派手でも条件なしなら重い』どおり、導線を付けず基本10 |
| 焚きつけ 7 | 盤面の🍂1枚につき3・🌱1つにつき2軽減(最低1) | カウント型の導線。盤面に🍂🌱が溜まるほど安く、燃やす対象(敵の🍂🌱)が増えるほど得になる。凩の魔女のパッシブ(🍂1枚につき-1)と重なって大きく安くなる点は要計測 |

## オブジェクトの算出（大岩基準・実測）

オブジェクトは『空きマスを選んで置く、置いている間ずっと効果を出す建造物』で、`objects.ts` が仕様の出典。**基準は大岩（効果なし・コスト1）**で、他の種類は『大岩 + 効果の価値』で値を付ける。**大岩以外の値は全て暫定**で、下の測り方で引き直す。

### 考え方

```
コスト = 大岩 1 + 効果の価値（勝率pt）÷ 2.7      ※効果が正なら下限2
```

- **本体の価値は0**: 大岩を無料で置いても勝率は変わらない（−0.4±1.4pt。ロックを外しても同じ）。マスを1つ塞ぐ得と損は釣り合っている。だからオブジェクトの価値は効果だけで決まる。
- **効果の価値 = 同じマスに大岩を置いた試合との勝率の差**。自分の2手番目に無料で置いて測る（同じ seed の対の差）。
- **2.7pt = 序盤に魔力1を払う重さ**。2手番目に大岩を置いて魔力4/8を払わせると −10.5/−22.1pt。魔力を貰う側の傾き（+2で+4.1pt、+8で+9.2pt、平均1.2pt）より重いのは、序盤に払うと手が止まるから。『貰った魔力の換算』で値を付けると高くなりすぎる。
- **寿命は『試合の残り』**: 置いたオブジェクトの約7割は試合終了まで残り、平均9手番働く（旧基準の『期待寿命3手番』は実測と合わない）。置くのが3手番遅れると価値は半分以下（大木 +13.8→+6.1、閻魔の舌 +18.3→+7.6、招き猫 +7.8→+0.9）。**早く置くほど得**なので、安いオブジェクトは序盤の定番になりうる。
- **検算は2通りで挟む**: `pay<C>`（2手番目に必ず置いて C を負債にする＝厳しめ）と `buy<C>`（魔力が C 貯まった最初の手番に払って置く＝甘め。高い価格は買えない試合が多く薄まる）。対照との差が0になる C が適正。値は『式・pay・buy の3つの中央』を丸めた。
- **上限寄りの値である**: AI は敵のオブジェクトを『ロックされた空きマス』としか見ず、壊しにも避けにも動かない。相手が対応すれば価値は下がる。相手が解体(4)を最初の機会に撃つと、大木・札・舌・聖域のどれも『大岩を解体させた』のと同じ勝率（+11〜13pt）になる＝効果はほぼ残らず、相手に魔力4を使わせた分だけが残る。**解体は『魔力4と設置コストの交換』**で、コスト4以下のオブジェクトに撃つと損、5以上に撃つと得。

### 測り方

```bash
# 価値: 対照・大岩・測りたい種類・魔力の換算表を同じ seed で
node sim/probe-object-value.js --arms none,boulder:quiet,spring:quiet,magic4 --chars you,witch --opps tactician,keysmith --games 50 --k 2 --seed 1 --out out/a.jsonl
# 価格の検算: pay<C>（厳しめ）と buy<C>（甘め）、相手が解体する ctr<C>
node sim/probe-object-value.js --arms pay3:spring:quiet,buy3:spring:quiet,ctr4:spring:quiet ... --out out/b.jsonl
node sim/probe-object-value-sum.js out [--by char]
```

置くマスは種類に合わせる: 自陣を強くするもの（砦・聖域・枯れた大木）は `own`、敵に効くもの（雷雲・毒沼）は `enemy`、それ以外は `quiet`。新しい種類を足すときは、同じ置き方の大岩との差を測ってから式に入れる。

## オリジナルスキル（プレイヤーが作る1枚・`customSkill.ts`）

作成画面で「対象（自陣/敵/空きマス/どのマスでも）・選び方（選択系=マスをn個選ぶ / 即発動系=全て・ランダムn個）・効果（いくつでも）・代償・手番終了」を選ぶと、コストは**式で自動算出**する（手で値を付けない）。人間席のデッキに1枠で1枚まで入り、AIは使わない。sim にも出ない。

```
コスト = round( Σ効果の単価 × 対象マス数の係数 ) + 2つ目以降の効果ごとに+1
         − ランダムなら1 − 手番終了なら2
         − 代償の割引（Σ代償の単価×0.7 を四捨五入。上の値の6割まで）    ※下限1
```

| 効果 | 単価（1マスあたり） | 根拠 |
|---|---|---|
| ライフ+n | n | ライフ3 = 3 |
| nダメージ | 1.3n（0で破壊するなら +1） | オピウム（全体-2・ターン終了）6 より、全体-2は重い |
| 破壊 | 4.5 | 敵コマ1つの破壊 4〜5。氷結中は❄が身代わり |
| 毒/帯電 ×k | 2k × 0.85^(k-1) | R3 |
| 火炎/氷結 ×k | 3k × 0.85^(k-1) | R3（氷結は1つ固定） |
| バッズ ×k | 4k × 0.85^(k-1) | R3 |

- **マスを使わない効果**（スキル封じ・ギア封じ）は相手全員に掛かる固定額で、対象マス数の係数を掛けず、足し算にだけ入る。これだけのスキルは対象の種類・選び方が意味を持たない。スキル封じは表示コスト（キャラ・ギア補正後）で判定し、チャージ・シャッフル・ロックは対象外。封じられた側の手番が終わると解ける。AI席にも掛かる（AIが選んだスキルを実行する段で弾く）。ギア封じはギアを持つ相手がいるときだけ使える。
- **対象マス数の係数**: n個選ぶ・ランダムn個 = n × 0.85^(n-1)（R3）、全て = 3.5（R4 の盤面全体。毒霧 6 より、敵だけを毒にする全体毒 7 は重い）。
- **効果を重ねるほど重い**: 単価は足し算、さらに2つ目以降は1つにつき+1（1手で複数の仕事をする割増）。最大4つ。
- **代償**（最大3つ・使うたびに必ず起きる）: 自陣のランダムな1コマへのダメージ/破壊/毒・火炎・帯電、または敵のランダムな1コマのライフ回復。割引は代償の単価の7割（R1'の自傷割安と同じ考え方）。**割引前のコストの6割まで**（下限1）。代償だけでほぼ無料にはできない。候補が無ければ不発（割引は残る）。
- 空きマス対象には、コマ専用の効果（ダメージ・破壊・ライフ・毒・バッズ）は付けられない。
