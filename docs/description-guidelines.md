# ゲーム内の説明文の書き方

スキル・キャラ・ギア・オブジェクトを追加・変更するときの指標。説明文は「何をするか」を一目で伝えるためのもので、仕様書ではない。

## 置き場所(唯一の出典)

| 対象 | 場所 |
| --- | --- |
| 汎用スキル(デッキに入るもの) | `deck.ts` の `SKILL_CATALOG[].desc`。手札のカード(`Game.tsx`)もデッキ編集画面も、ここを読む。`Game.tsx` に説明文を二重に書かない |
| キャラ固有スキル | `Game.tsx` の該当 `SkillButton` の `paragraph` |
| ジャンルとエフェクトの意味 | `deck.ts` の `CATEGORY_HELP`。ジャンルの見出し(デッキ編集)とカードのジャンルタグのツールチップに出る |
| キャラ | `App.tsx` の `CHARACTERS[].passive` |
| ギア | `gear.ts` の `GEARS[].desc` |
| オブジェクトの効果 | `objects.ts` の `desc`(マス上のツールチップ用) |

数値・条件・例外などの細かい仕様は `docs/characters.md` / `docs/objects.md` / `docs/skill-cost-rules.md` に書く。

## 書かないもの

- **エフェクトの説明**(🌱🍂☠⚡❄🔥🔑📜が何をするか)。スキルやキャラの説明では絵文字・名前を出すだけにして、意味は `CATEGORY_HELP` に1か所だけ書く。新しいエフェクトを足したら、そのジャンルの `CATEGORY_HELP` に1〜2文足す
- **細かい仕様**: コスト軽減の条件、下限・上限、ターン数・確率・ダメージ量、対象外の例外(🔑ロック・⚡無敵・氷結中は除く、など)、「対象が無いと使えません」
- 実装の都合(他スキルとの相互作用、重ならない、リセット条件)

## 必ず書くもの

- **使用回数の制限**(「ターン1回」)。トークン系スキルなど、ゲームの進め方に直結するため省かない。末尾に「（ターン1回）」の形で付ける。括弧書きを使ってよいのはこの制限だけ

## 書式

- **体言止め**で統一する(「〜する」「〜します」「〜できる」で終えない)。1文、句点「。」で終えない
  - 動詞は名詞形・サ変名詞にする: 設置、付与、除去、破壊、軽減、獲得、増加、変換
  - 効果が状態の説明になるときは、「〜が安くなる」「〜が減らない」のように言い切りの形でよい(文末は名詞または言い切り)
- 補足の括弧は入れない(上記の使用回数だけ例外)。補足が要るなら、その内容は仕様として docs へ
- キャラの説明は、特徴を1〜2文で言い、最後に「固有: スキル名」(複数は「・」区切り)
- オブジェクトの設置スキルは「空きマスに〇〇を設置。<効果>」の形にする
- 既存のスキルの語彙にそろえる(「選択」ではなく「選ぶ」、付与・除去・破壊など)
- 数値を入れるのは、そのスキルの名前や本質に関わるときだけ(例: ライフ3、トリプルロックの3マス)

## 例

- ○ `マスを選んで毒を付与`
- ○ `空きマスにランダムでコマを設置（ターン1回）`
- × `マスを選択し、毒を1付与します（重複可）。毒は時間とともにライフを減らし、尽きると…`
