# オブジェクト — 共通の仕様

空きマスに設置して使う建造物。コマと違い列（勝利判定）に数えず、ライフは時間で減らない。
**実装の唯一の出典は `src/components/game/objects.ts`**（数値・説明文・手番開始時の効果）。本番（`Game.tsx`）と sim（`sim/engine.js`）が同じ関数を呼ぶ。
個別の追加は「新しい種類を足すとき」の手順に従う。コストの根拠は [skill-cost-rules.md](skill-cost-rules.md) の「オブジェクトの算出」。

## 1. 持ち方
- `SquareInfo.object?: ObjectKind` で持つ（`src/types/ObjectKind.ts`）。持ち主 = `player`、ライフ = `bind`、エフェクトは `effects`。
- 📜マーカーのエフェクトにしなかったのは、エフェクト数を数えるスキル（彩りの庭・闇鍋・焚きつけなど）がずれるのを避けるため。コマを作り直す経路（乗っ取り・破壊）では `object` は自然に消える。

## 2. 設置
- スキル（汎用スキル idx 105〜）を使ってから、設置先の空きマスを選ぶ（`objectLandable`）。
- 選べるマス: コマ・オブジェクトが無く、氷結中でも🔑ロック中でもない空きマス。埋まったマスを選んでも選び直せる。
- 初期ライフは種類ごと（`OBJECT_DEFS[kind].life`）。空きマスに乗っていた🔥は引き継ぐ（大木系は設置の直後に燃え尽きる）。
- トークンではないので、ターン1回の制限はない。設置数の上限もない（自陣のオブジェクトはいつでもコマで置き換えられるため）。
- AI は現状設置しない（#399）。

## 3. 勝利判定・減衰
- 列に数えない（`util.ts` の `lineSymbols`）。4つ並んでもオブジェクトは勝利にならない。
- 自然減衰（毎着手／3人以上は1周ごと）と満杯の追加減衰を受けない（`thermal.ts` の `decayTick`、`decay.ts` の `crowdedDecay`）。
- 🔥の継続ダメージ・毒など、**エフェクトによるライフ減少は通常のコマと同じように受ける**。

## 4. 乗っ取り（`placement.ts` の `resolvePlacement`）
| 対象 | 条件 | 結果 |
|---|---|---|
| 自陣のオブジェクト | いつでも（制限なし） | 通常のコマで置き換え。オブジェクトは消え、ライフは着手のライフ |
| 敵のオブジェクト | **ライフ0でないと不可** | 下記の2択 |
| 敵のオブジェクト（ライフが残る） | 巨人・満杯の盤面だけが殴れる | ライフが減るだけ。削り切っても0で止まり、乗っ取りは次の着手 |

ライフ0の敵のオブジェクトを乗っ取るときは**選べる**:
- **自陣のコマにする**（既定）: オブジェクトは消えて、ライフが着手のライフの通常のコマになる。
- **自分のオブジェクトにする**: 同じ種類のまま持ち主が自分に変わる。ライフは着手のライフ。

人間の手番では、該当するマスを押すと選択ダイアログが出る（`Game.tsx` の `captureChoice`）。AI は常に前者。sim は `s.captureAsObject` で選ぶ。
どちらも通常の乗っ取りと同じく、敵のコマを奪ったことになる（復讐の刃・墓地の対象）。

## 5. エフェクト・スキルの影響
- エフェクト（🔥❄⚡☠🌱🍂🔑）とスキルは通常のコマと同じく受ける。
- **氷結中**のオブジェクトは休眠して、手番開始時の効果を発揮しない。解凍すると再び働く。
- **大木・枯れた大木**は🔥を付けられると即座に壊れて空きマスになる（`thermal.ts` の `ignite`）。氷結中は🔥の代わりに氷結が解けるだけ。取りこぼし用に手番開始時にも `sweepBurntTrees` で掃除する。
- 破壊系のスキル（鬼門封じ・パーフェクトゲームなど）でコマとして破壊される。

## 6. 手番開始時の効果
持ち主の手番が始まるとき、`Game.tsx` の `[currentTurn]` の effect と `sim/engine.js` の `advanceTurn` が `objectTurnStart` を呼ぶ。
- 順序: 絶対零度の爆破などの後 → 大木系の🔥掃除 → オブジェクトの効果 → 手番開始のマジック計算（`turnStartMagic` の `objects` に大木のマジックを足す）→ ライフ抽選（`objectLifeBonus` を足す）。
- 複数あれば全て働く（大木2本ならマジック+6）。マス番号の昇順に処理する。
- 周囲八マスは `geometry.surroundRange`（盤の端は欠ける）。ランダム選択は、🔑ロック・⚡無敵でないコマから乱数で1つ。候補が無ければ何も起きない。

| 種類 | 初期ライフ | 手番開始時の効果 |
|---|---|---|
| 大木 🌳 | 3 | マジック+3。🔥で即壊れる |
| 枯れた大木 🪵 | 3 | 周囲八マスのコマのランダムな1つに🍂。🔥で即壊れる |
| 生命の泉 ⛲ | 4 | ライフ期待値+2 |
| 砦 🏰 | 6 | 周囲八マスの自陣のコマ（他の自陣オブジェクト含む）のライフ+1 |
| 雷雲 🌩️ | 3 | 周囲八マスのコマのランダムな1つに⚡ |

## 7. 表示
- マスの中央に絵文字、右下にライフ（`Square.tsx`）。実線の縁で式神（点線の縁）と区別する。
- 手札のカードはカテゴリ「オブジェクト」。

## 8. 新しい種類を足すとき
1. `src/types/ObjectKind.ts` の `OBJECT_KINDS` に追加し、`objects.ts` の `OBJECT_DEFS`（名前・絵文字・ライフ・説明）と効果（`objectTurnStart` か、ライフ補正のような別関数）を書く。
2. `skillCosts.ts` にコスト、`deck.ts` の `SKILL_CATALOG` にカタログ（idx は `OBJECT_SKILL_BASE_IDX + OBJECT_KINDS の添字`）、`AIPlayer.ts` の `SKILL_POOL_SIZE` を増やす。コストは必ず `skill-cost-rules.md` の基準で出し、算出を追記する。
3. `Game.tsx` の `executeSkillForAI` の `switch` に `onClick…` を追加、`sim/engine.js` の `SKILLS` と `sim/duel.js` の `IDX_SKILL` に追加。`skillEffects.test.tsx` に演出を登録する。
4. `node scripts/gen-sim-shared.js` を実行してコミットする。
5. `objects.test.ts`（純粋ロジック）、`sim/engine.test.js`（sim）、必要なら `Game.objects.test.tsx`（UI）にテストを足す。
