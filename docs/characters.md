## 共通ルール

| 項目 | 内容 |
|---|---|
| 盤面 | 2人=4×4（16マス）。3人以上は人数で拡大（下記「多人数戦」）。**同じ記号を縦横斜めに4つ連続**で並べたら勝ち（盤が大きくても4つのまま） |
| ライフ (bind) | 各マスの耐久値。着手のたび**盤面全体で −1**（毒があればさらに毒スタック分−1） |
| 空きマスに置く | 自分のコマをライフ = そのターンの**ライフ値**で設置 |
| 自分のコマに重ねる | ライフ + (ライフ値 + 1) で強化 |
| 敵のコマを攻撃 | `敵ライフ − ライフ値 + 1` → 負なら**奪取**（絶対値がライフに）、0なら**破壊**、正なら削るだけ |
| 攻撃の制限 | **ライフ0の敵マスしか触れない**（例外: 巨人はライフが残っていても殴れる） |
| ライフ値 | 毎ターン**正規分布**で再抽選（平均はキャラごと、**σ=3**）。0以下なら1に補正 |
| 開始マジック | 両者 **2** |
| 毎ターンの魔力 | **+1** ＋ 自陣のバッズ🌱の数（キャラ補正は下表） |
| スキル枠 | 全**27種**から毎手番ランダムに**3枠**。最大3つまで🔒ロックで固定できる |
| シャッフル | コスト**1**。ロック分を残して引き直す（プールは全53種） |
| 🔑ロック | そのマスを6ターン以上固定。ロック中は誰も触れない |
| 🌱バッズ | 自陣にあると毎ターン魔力+1（魔法使いのみ+3） |
| ☠毒 | 毎ターン、スタック数だけ追加でライフを削る。重複可 |
| ⚡帯電 | 汎用の帯電スキル（と雷霆の巫の固有スキル）で付く。帯電マスの隣に誰かが着手すると、その帯電マスの縦横隣のコマが1ダメージ。発火した⚡は全部消える。詳細は[⚡帯電のルール](#⚡帯電のルール) |
| ❄氷結 | 氷結系スキルで付く（重ならない）。詳細は[❄氷結・🔥火炎のルール](#氷結火炎のルール) |
| 🔥火炎 | 火炎付与系スキルで付く（重複可）。毎ターン1スタックにつき2ダメージ。詳細は同上 |

### ❄氷結・🔥火炎のルール

実装は `src/components/game/thermal.ts`（ヘッドレス版 `sim/thermal.js`、`thermal.test.ts` が一致を確認）。

**❄氷結**（スタックする。❄が1つでもあれば氷結中。🔑・🔥のないマスに付く。**空きマスにも置ける**）
- **氷結中の空きマスには、🔑ロックと同様に誰も着手できない**（トークンのランダム設置先からも外れる）
- **休眠**: 氷結中のマスの他のエフェクト（🌱バッズ・⚡帯電・☠毒）は**消えないが効力を発揮しない**（🌱は魔力ボーナスに数えず、⚡は発火源・ジャマーの起点・雷霆の巫の無敵にならず、☠は継続ダメージを与えない）。解凍すれば再び働く
- 氷結中のマスには**🔑ロックを掛けられない**
- ターン進行でライフが減らない（自然減衰も🔥の継続ダメージも）
- **隣接する⚡のダメージ（発火・ジャマー）を受けない**
- **スキルでダメージを受けるとき、ダメージを受ける代わりに❄が1スタック減る**（ストンプ・審判の日・スラッシュ・オピウム・式神の爆破など。ライフ0化・破壊も1スタックが肩代わり）
- **自陣のコマへの上書き（強化）ができなくなる**
- 縦横隣のマスに🔥が付く（発火する）と、**全スタックが即座に解除**される
- **氷結中のマスに🔥を付けようとすると（後から火炎を付与）、🔥の代わりに❄が全スタック解除される**（🔥は付かない）。🔥が実際に付いたマスの**縦横隣（横に火炎を付与）**の氷結も全スタック解除される
- 通常の着手で敵コマを奪取・破壊したときは、マスの効果ごと消える

**🔥火炎**（スタックする）
- **他エフェクトとの関係**: 火炎は休眠させない。⚡・☠は🔥中も**働く**。後から🔥が付くと🌱は消える（冬至の種子のガード中は残る）。🔥が付いた後に足した🌱は残る
- **🔥を付与した瞬間に、そのマスのコマへ1スタックにつき1ダメージ**（🔑でない・氷結中でないコマのみ。空きマスや氷結中のマスには入らない。このダメージでは🔥は消えない）
- **🔥でライフが0になったコマ（すでにライフ0のコマに付けた場合も）は破壊され、空きマスになる**（継続ダメージ・付与時のダメージのどちらでも。🔑ロック中・氷結中は除く。破壊したマスにはそれ以上🔥を付けない。墓地は増えない＝毒で消えるときと同じ）。自然減衰だけで0になったコマは従来どおり残る
- ターン進行のたび、1スタックにつき**2ダメージ**（ライフ0が下限。氷結中・🔑中は受けない）。**煉獄の鍛冶師が（持ち主以外に）いると、1マスの1回の継続ダメージにつき追加で+1**
- ダメージを受けると**全スタックが消える**（スキルのダメージ。**毒・電気のダメージでは消えない**＝☠・⚡と🔥は重複して働き続ける）。**自然減衰と🔥自身の継続ダメージでは消えない**（スタックの減衰なし）
- 🔥のマスが**スキルでダメージを受けるとき1.5倍**（切り上げ。毒・電気には倍率なし）

### ⚡帯電のルール

発火と過負荷は、誰が⚡を付けても同じ（帯電トークン・帯電付与などの汎用スキルでも、雷霆の巫の固有スキルでも）。
- 誰かが（通常の着手で）⚡マスの縦横隣のマスに置くと、その⚡マスの**縦横隣接のコマ**がライフ−1
  （ライフ0のコマ・🔑ロック中のコマは対象外。⚡マス自身は無傷。置いたばかりのコマも隣なら対象）
- **⚡が乗った時点のダメージ**: 雷霆の巫**以外**のコマは、⚡が乗った瞬間に**2ダメージ**（帯電付与・帯電拡散・範囲帯電・ランダム帯電・帯電トークン類。ライフ0・🔑ロック中・氷結中のコマと空きマスは受けない。🔥は消えない）
- 発火した⚡は**全部消える**。連鎖はしない。トークンの設置やスキルでの付与では発火しない
- **過負荷**: ⚡を増やした結果、盤面の**全マス**（空きマスも）に⚡が付いたら、全⚡と🔑ロックが消えて**全マスのライフが0**になる（コマは壊れない）。
  ターンは終わらないので、起こした側がそのまま奪える。高エネルギーで爆発するイメージ
- 敵味方問わず発火するので、**自分の着手で自軍を削らない配置**が要る

### 多人数戦（3〜8人・ホットシート）

| 人数 | 盤面 | 記号（席順＝手番順） |
|---|---|---|
| 2 | 4×4 | 💙 ⭕ |
| 3〜4 | 5×5 | 💙 ⭕ 🟩 🔶 |
| 5〜6 | 6×6 | … ⭐ 🟣 |
| 7〜8 | 7×7 | … 🟫 🩷 |

- **マス数は人数と無関係に選べる**（開始画面の「マス数」: おまかせ / 4×4〜10×10）。「おまかせ」だと上の表の盤面になる。
  勝利は4連続のままなので、人数に比べて盤が狭いと混み合い、広いと決着が遅れる（バランスは未検証）
- 手番は席順に回る。**同じキャラを複数人が選べる**。各席は人間/AIを個別に選べる（人間は同じ画面で交代して操作）
- 「相手」と書いてあるスキルの効果は、**自分以外の全員**に及ぶ:
  オピウム・式神の爆破は周囲の敵コマ、チューチュートレインは全員の魔力、両トークンは全員に1つずつ、
  蘇生の吸収は全員のライフ0のコマが対象
- 巨人は2ターンに1回しか動かない。手番は「全員1周→巨人を除いて1周」の繰り返し（2人戦で両者が同キャラのときは休みなし）
- ⚡帯電は、**誰の着手でも**⚡マスの隣に置けば発火する。雷霆の巫が複数いるときは、それぞれの席の⚡付きコマが無敵（盤の大きさに応じて縦横に隣接するマスだけが対象）。多人数での強さは未計測（issue #39 の備考）
- スラッシュ/バックスラッシュは盤の対角線**全体**（一辺のマス数ぶん）、審判の日は行・列・両対角、ストンプは周囲3×3
- ライフの減衰は、2人戦は「**着手のたびに盤面全体で −1**」（従来どおり）、3人以上は
  「**手番が1周するごとに1回だけ −1**」（着手N回につき1回。issue #30）。毒の追加減衰・ロックの解除も同じタイミング。
  人数が増えるとコマが短命になりすぎるのを避けるため
- **終盤の魔力ボーナス（全人数）**: 50ターンごとに、手番開始時に得られる魔力が**全員**+1ずつ増える
  （ターン50で+1、100で+2…。長引く試合の打ち切り用。画面の「魔力ボーナス +N」で確認できる）
- **sim/（ヘッドレス）も2〜8人に対応**（`node sim/cli.js sim --players N`。issue #32）

## キャラクター別

### 🧑 あなた — 無特性

**コンセプト**: 何の補正も持たない基準点。固有スキルもない。

**強み / 弱み**
- ライフ平均5・コスト修正なしで、**引いたスキルをそのまま素直に撃てる**
- 固有スキルが無いぶん、盤面を動かす爆発力が無い。**27種のランダム枠が実力のすべて**

**立ち回り**
1. ロックを活用する。固有スキルが無い＝手札運に一番左右されるので、
   トークン系や強いスキルを引いたら**積極的に🔒で固定**する
2. 序盤はトークンで面を取り、リーチを2本同時に作る（フォーク）ことを最優先
3. 相手の固有スキルの発動条件（軍師のトークン回数、魔法使いのスキル使用回数、
   ネクロの墓地）を**貯めさせない**。無駄なトレードを避ける

### 🎖️ 軍師 — トークン展開

**コンセプト**: 安いトークンで盤面を数で埋める。単発の強スキルは苦手。

**パッシブ**
- トークン系スキルのコスト **−1**、それ以外 **+2**
- 自分が置くトークンのライフが **6**（通常4）

**固有スキル: 全軍突撃**
- コスト `9 − これまでのトークン使用回数 × 2`（**使用後カウントはリセット**）
- 発動後**3ターン**、自分の着手が終わるたびに空きマスへライフ0のコマを1つ設置

**立ち回り**
1. **まずトークンを撃つ**。全軍突撃のコストがトークン1回につき2下がるので、
   トークンを3回使えば実質3で撃てる。**貯めてから撃つスキル**であって、開幕に撃つものではない
2. ライフ6のトークンは相手が奪いにくい（相手のライフ値6以上が必要）。
   **盤面の「触れないマス」**として使い、そこを軸にラインを作る
3. トークン以外は+2と重いので、**ロックはトークン系に絞る**（AIもそうしている）

**弱み**: 破壊系・防御系スキルが軒並み+2で、相手のリーチを崩す手段が薄い。
ライフ0のコマがばらまかれるので、**相手に奪われて逆に材料を渡す**リスクもある。

### 🧙 魔法使い — バッズ経済

**コンセプト**: バッズ🌱を植えて魔力を回し、スキルを連打する。本体は紙。

**パッシブ**
- 毎ターンの魔力が **+2**（基本+1 ＋ キャラ補正+1）
- さらに**自陣のバッズ1個につき +3**（通常キャラは+1）
- ライフ平均 **4**（低い）

**固有スキル: 審判の日**
- コスト `11 − これまでのスキル使用回数`（下限0、**使用後リセット**）
- 選んだマスを中心に十字＋斜めの広範囲を破壊し、中心に自分のコマ（ライフ2・バッズ付き）
- **ターンが終了する**

**立ち回り**
1. 序盤はバッズを2〜3個植えることに投資する。バッズ2個＝毎ターン+7魔力で、
   **中盤以降スキルが撃ち放題**になる
2. バッズ駒は🔑ロックで守る（AIもこれをやる）。バッズを剥がされると経済が死ぬ
3. 審判の日は**安いスキルを撃った回数だけ安くなる**。バッズで魔力が余るので、
   小スキルを回す→コストを削る→広範囲破壊、という流れが本線
4. 破壊範囲に**自分の駒を置かない**布陣を意識する（自軍も巻き込む）

**弱み**: ライフ平均4なので置いたコマが脆く、**バッズを守り切れないと何も起きない**。
増殖との相性は全キャラ最良（後述）。

### 👹 巨人 — タンク／制圧

**コンセプト**: 圧倒的なライフで殴り合いを制する。ただし手数が減る。

**パッシブ**
- ライフ平均 **10**（最高）
- **2ターンに1回しか行動できない**（巨人を除いた周が1周挟まる）
- **ライフが残っている敵マスにも攻撃できる**（他キャラはライフ0の敵しか触れない）

**固有スキル: ストンプ**（コスト3）
- 選んだマスと**周囲1マス（最大3×3）**を破壊。自軍は −5 で済む（全壊しない）
- 中心が空いていれば自分のコマを置く。**ターンは終了しない**（このあと通常の着手ができる）

**立ち回り**
1. **殴れるのが最大の特権**。相手のライフ6の駒でも、ライフ8を引けば奪える。
   相手の要所（ラインの交点、バッズ駒）を能動的に潰しに行く
2. ストンプは**敵2体以上が範囲に入るとき**に撃つ（AIの基準もこれ）。
   撃った後も着手できるので、「ストンプで割る→空いたマスに置く」の2手が1ターンで通る
3. 手番を1/5落とすので、**1手の価値を最大化**する。トークンで手数を補うのも有効

**弱み**: 手数不足。魔力ボーナスが無いのでスキル回転も遅い。
過去のバランス調整で「ライフは高いまま、魔力供給を絞る」形に落ち着いた経緯がある
（`sim/BALANCE.md` Phase 3.1）。

### ☯️ 陰陽師 — 式神

**コンセプト**: 紙の分身「**式神**」を陰で仕込み、陽で爆破して敵陣を崩す。

**パッシブ（モード依存）**

| | ライフ平均 | 毎ターン魔力 | コスト |
|---|---|---|---|
| 陽 | **7** | +1 | 全スキル **+1** |
| 陰 | **4** | **+2** | 修正なし |

**式神（📜）とは**
- 紙の分身のコマ。**ライフ2**、列の並び（4連）には**数えない**
- 自分で**補強**する（自分の式神のマスに着手する）と、式神ではなく**🌱付きの自陣コマ**になる
- 相手に**乗っ取られる**（ライフ0になった式神にコマを置かれる）と**空きマス**になる（相手のコマは置かれない）
- 他のコマと同じく減衰・ダメージ・破壊の対象

**固有スキル**
- **陰陽転化**（コスト1）: モードを切り替える
- **式神設置**（陰のみ・コスト3）: **任意の空きマス**に式神を置く。手番は続く
- **式神爆破**（陽のみ・コスト5）: 自分の式神を1つ選んで爆破する。式神は消え、**周囲8マスの敵のコマに4ダメージ**（0になったら破壊）。**周囲の空きマスは自分の式神になる**（自陣のコマは無傷）

**汎用スキル（全キャラのデッキに入れられる）**
- **式神一括**（コスト**式神1体につき3**）: 自分の式神を全て通常の自陣のコマにする（列に数えられるようになる）。式神が多いほど高い（盤面を埋めると30魔力超）
- **百鬼夜行**（コスト7）: 着手できる**全ての空きマス**に、**ライフ0**の式神を置く（氷結中の空きマスは除く）。ライフ0なので相手が着手すれば消えるが、**式神一括と続けて撃つと、盤の空きが全て自コマになって列が完成する**
- **式神ランダム設置**（コスト2・トークン扱い）: ランダムな空きマスに式神を置く。トークン系のスキル・ギアの影響（コスト補正・ターン1回の制限・ライフ補正）を受ける

**立ち回り**

2. 猛毒化（毒の数を倍化）は盤面に毒が多いほど爆発する。**終盤の決め手**
3. 拡散パッシブがあるので、**毒持ちの駒をわざと相手に取らせる**のも手
4. 自陣の毒はライフを上げる（自分は毒で硬くなる）。血清で消すかどうかは、

**弱み**: 毒以外が全部+1で、防御・展開が重い。決着が遅いので**速攻に弱い**。

## デッキ

手札の3枠は、**席ごとのデッキ（汎用スキル12枚）**から毎手番ランダムに引く（ロックしたスキルは残る。シャッフルもデッキから引き直す）。

- デッキは開始画面の「デッキ」（各プレイヤーのカード内）で組む。汎用スキルから**ちょうど12枚、同じスキルは1枚まで**。12枚でないと対戦を開始できない。
- **未指定は「推奨デッキ」**（`src/components/game/deck.ts` の `RECOMMENDED_DECKS`）。人間も同じ。「推奨」ボタンで戻せる。🎲でランダムなデッキ。
- **AI席**は、何も指定しなければキャラの推奨デッキをベースに、**3枚をデッキ外のスキルとランダムに入れ替える**（試合ごとに少し顔ぶれが変わる）。AIがデッキを指定した場合（`PlayerConfig.deck`）はそのとおり。
- キャラ固有スキルと常設スキル（チャージ・シャッフル・ロック・氷室の番人の氷結）はデッキと無関係に常に使える。
- **デッキ編集**: スキルはカテゴリ（トークン・攻撃・場の操作・強化補助・バッズ・毒・帯電・氷結・火炎）ごとに並ぶ。スキルにカーソルを合わせる（タップ・フォーカス）と、効果と基礎コストが出る（チップの title にも同じ説明）。
  組んだデッキは名前をつけて**ブラウザに保存**でき（最大20個、同名は上書き）、選んで読み込み・削除できる。保存先は localStorage（`ticatactoe.decks`）で、プライベートウィンドウなど使えない環境では保存できないだけでゲームは動く。
- 推奨デッキの初版は手組み（AIが使いこなせる汎用スキルを核に、キャラの得意に振った）。強制使用A/Bの結果で見直していく。

### 細かい仕様

- **コストの順序**: キャラ補正（軍師のトークン-1/他+2 など）→ ギア補正。ギアで**下げる**ときは下限1（もともと0のコストは0のまま）。
  四連の極意の無料だけは0にする。価格破壊だけは例外で、キャラ補正の**前**の基礎コストに足す（下限1）
- **対象のスキル**: ギアのコスト補正・スキル使用数は、汎用スキルと固有スキルのすべてに掛かる。
  チャージとシャッフルは対象外（スキル使用に数えない）。価格破壊も蘇生（墓地と連動）・チャージ・シャッフルは固定
- **幸運の財布**はコストが0になるだけで、スキル使用には数える（連鎖割引・四連の極意・余韻は進む）
- **空蔵**: 期限切れでできるコマの持ち主は「ロックをかけた人」。ライフは1なので、次の減衰で0になり奪われやすい
- **道連れの鍵**: ロックが付いたコマはライフが（堅牢の鍵があれば9、なければ6まで）引き上げられる。両トークンは自分のコマだけが対象
- **収穫**: ロックは1マスにかけるごとに+1。バッズは「次の一手で植える」と宣言した時点で数える。ワルプルギスの夜・帯電拡散・ミアズマ・パンデミック・猛毒化は付与した数（上限5）
- **毒花**: 毒が付いたコマ1つにつきバッズ1つ。持ち主が装備していれば、毒を付けたのが自分でも相手でも（ミアズマ・毒霧・毒の拡散・増殖の毒も含む）発動する。毒を付ける側の装備は関係なく、敵のコマに付けた毒ではバッズは付かない。防御側の性質もある
- **伝播**: バッズ=周囲の自陣のコマ / 毒=周囲の敵のコマ / ⚡=誰のコマでも。ロック中のコマと⚡無敵のコマは対象外。対象がなければ何も起きない
- **復讐の刃**: 通常の攻撃での**奪取**と、ネクロマンサーの蘇生による**吸収**が「奪われる」に当たる（破壊・スキルでのライフ減少は当たらない）。
  奪取した側の-1は通常の攻撃だけで、吸収は対象外。魔力は0未満にならない。多人数では誰に奪われても発動する
- **彩りの庭**: エフェクトは🌱🔑☠⚡❄🔥の種類で数える（同じ種類の重ね掛けは1種類）。数えるのは手番開始時の自陣
- **病炎の契り**: 「固有」は全軍突撃・ストンプ・審判の日・陰陽転化・舞・蘇生・ミアズマ・帯電拡散・絶対零度・業火。相手の毒・火炎は数えない
- **廃墟の底力**: 「破壊」は自陣のコマが盤から消える・持ち主が変わること。相手の通常の着手による奪取と、自分の着手マスは数えない。割引は破壊された手番の次の自分の手番の終わりまで
- **焦土**: 手番の頭と終わりの盤面を比べ、同じ持ち主のままで🌱が減り🔥が付いているマスを数える（冬至の種子のガード中は消えないので対象外）。魔力は発動の瞬間に得る
- **灰の供物**: 手番の頭と終わりの盤面を比べ、相手のコマで🔥が増えたマスを数える（業火なら敵の全マス）。割引は次の自分の手番に入って、その手番が終わるまで。重ね掛けは足し算で、下限1
- **凍てつく根**: 氷結中のマスは🌱が魔力に数えられないので、それを敵味方問わず魔力に換える。バッズ系のキャラの強みを氷結で止めつつ魔力にできる
- **伝導**: ⚡が乗っているコマの持ち主が装備しているときだけ働く。移すのは、ダメージを受けた敵のコマ（持ち主以外）への☠/🔥の各1スタック。🔥は通常の火炎付与と同じ規則（付いた瞬間に1ダメージ・縦横隣の氷結が解ける）。コマのない⚡マスや、持ち主自身のコマには移らない
- **土壇場の防壁**: 1席につき1度だけ。揃っていた列（複数なら全部）と、持ち主の自陣のコマがすべて空きマスになり、試合は続く。ボーナスは持ち主以外の全席に、発動後ずっと掛かる
- **AI**: ギアは使えるが、ギアに合わせた戦い方は**していない**（コストの見積もりにギア補正を反映するだけ）
