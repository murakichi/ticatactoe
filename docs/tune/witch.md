## 診断
### 勝ち筋
- パッシブ: 盤面の🍂1枚につきスキルコスト-1（下限1）。虎落笛（コスト7）: 自陣の🍂の枚数ぶん敵全てにダメージ＋自陣のライフ+2。
- 勝ち筋は「自陣に🍂を2枚以上保つ → コストが安くなり虎落笛が撃てる」。威力ではなく**🍂の供給**が律速。

### ファネル（witchの手番ごと、40試合、vs magician/giant/poisoner/necromancer、seed 500+）
- 手番開始時の魔力: 平均 2.3〜2.9（コスト7の虎落笛は撃てない）。試合は魔女の手番で5〜8回で決着。
- 自陣の🍂: 1手番あたり 0.02〜0.12 枚。P(🍂≥2)=0〜0.02、虎落笛の発動は **0回/40試合**（4対戦とも）。
- 敵コマ2つ以上: 0.7〜0.8（条件として厳しくない）。🍂付きトークン: 0.05〜0.53/試合、置き土産: 0.3〜1.1/試合、焚きつけ: 0。

### 上限実験（`scratchpad/cheat.js`、6相手×40試合、witch 総合勝率）
| 条件 | 勝率 |
|---|---|
| 基準 | 18.8% |
| 魔力 +2/手番 | 67.1% |
| 魔力 +5/手番 | 85.0% |
| 🍂を毎手番1枚タダで自陣に追加（魔力は基準のまま） | 76.7% |
→ **律速は🍂の供給（と魔力）**。🍂が1枚でも安定して生きれば勝率は4倍になる。

### 観戦（witch vs magician, seed 900/901）
- 手札のトークン（Tk）をロックして毎手番4を払い、🍂付きトークン（5, ギアで4）に魔力が回らない。
- 🍂を作っても、それが乗ったコマが3〜4手で減衰・奪取で消え、🍂も消える（T9:1枚→T11:0枚）。

### 仮説
1. **魔力の温存**（手札に🍂トークンがあるとき、その最安コスト未満になる他スキルの支払いを控える）→ 反証済み（#1）。
2. 🍂を乗せたコマを守る（そのコマにロックを優先して掛ける）→ 未測定。ロック中は奪取されず、減衰でも🍂が残る。
3. 🍂供給に効くギア → 走査の結果、価格破壊（priceWreck）のみ有意（+11.9pt）。余韻・幸運の財布・連鎖割引は誤差内（-1〜+5pt）。priceWreck は試合開始時に全スキルのコスト表をランダムに引き直す。魔力が足りず「コストが安く引けた試合だけ」🍂トークンが回る魔女に効く（仮説）。
4. 焚きつけ（敵の🍂3枚以上で撃つ）の閾値と、置き土産を撃つ数（今は1手番1回）を緩める→ 未測定。
