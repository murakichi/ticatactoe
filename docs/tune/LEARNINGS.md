## 計測のコツ

- 2026-10-20: `--scan gears`(30通り×9相手×60試合)は4コアで約20分。必ず `--cache .tune-cache` を付けてバックグラウンドで走らせる。同じ seed/games でも rank 表(56.3%)と scan の基準(59.3%)がずれた=SE≈4pt のノイズ。数pt差の判断は200試合以上で。

- 2人戦1試合 ≈ 0.3秒(4コア並列)。`--target` 1設定 ×100試合 ≈ 数十秒〜1分(2026-10-20, 初回計測)。
- `--rank --games 60` は約3分(4コア)。`--scan gears --games 60` は10分超で、Bash の600秒タイムアウトを超えるので最初から `run_in_background` で回す(2026-10-20, necromancer)。
- 注意: `nohup ... &` のバックグラウンド実行は応答をまたぐと死ぬことがある(出力0バイトで消えた)。長い走査は Bash の run_in_background で。jest は `npm test -- --watchAll=false` を使う(`npx jest` は ts を読めず全滅)。
- 少数試合(20試合)の環境勝率は ±7pt 程度で、順位の判断には使えない。探索は60〜100試合、採用の再測定は200試合以上。
