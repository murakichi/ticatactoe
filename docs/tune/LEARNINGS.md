## 計測のコツ

- 2人戦1試合 ≈ 0.3秒(4コア並列)。`--target` 1設定 ×100試合 ≈ 数十秒〜1分(2026-10-20, 初回計測)。
- 少数試合(20試合)の環境勝率は ±7pt 程度で、順位の判断には使えない。探索は60〜100試合、採用の再測定は200試合以上。

## 効いたこと / 効かなかったこと

- 2026-10-20 giant: `--scan gears`(約32近傍×60試合)は4コアで約17分。巨人は titanCost+sturdy が既に局所最適で、1枠差し替えは全て基準以下(最良 priceWreck +0.9pt は誤差)。gear軸はまず後回しにして deck/strategy を先に測ってよい(seed1, 60試合)。
- 2026-10-20 giant: デッキ1枚差し替え30近傍(60試合)は基準±2pt内に一様に分布し、最良でも z≈0.6。1枚差し替えでは巨人のデッキは動かない(局所最適)。ただし1回の `--scan deck` が約20分かかるので、背景実行は `run_in_background` で。`nohup ... &` で起動したスキャンは出力が空のまま消えることがあった。
- 2026-10-20 giant: 巨人は固有スキル(stomp)が1試合0.4回・全スキル合計でも1回未満。AIの発動閾値(敵2体以上)を緩めても発動数は変わらず、律速は魔力。AIの条件分岐を疑う前に probe-usage の使用回数が閾値依存かを小さいノブで先に確かめると速い。
- `--swap 3 --cat X` は、そのカテゴリの未採用札が3枚以上ないと候補が0件になる(attackは2枚のみ)。
- 2026-10-20 giant: `--opp X` に絞ると1枚差し替えの差が大きく出る(対cryomancer 40近傍×200試合で最良+9pt)が、環境全体の再測定では+0.5ptに縮んだ。特定相手向けの札(火遁=氷解凍)は他に効かない → 全体勝率で採用するなら再測定必須(seed2,200試合で足りる)。
