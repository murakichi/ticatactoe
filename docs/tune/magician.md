## 検証: #160（風の落とし子→刈り入れ前夜の連鎖）は魔法使いの戦略として使えるか — 実用性は低い
**魔力そのものは序盤ほど効く**（上限実験, seed9/200, 基準 56.8%）: 毎手番+1 全期間 67.2 / +3 全期間 74.7 / +3 を4手番目まで 65.1 / 10手番目まで 71.7 / 10手番目以降 64.6。+20,+40,+80 は 75.4 で飽和。魔法使いは序盤の魔力が律速。
**だがループでは序盤に魔力を作れない**: 連鎖割引ギアで 風の落とし子(3)+刈り入れ前夜(2) が 1+1 に張り付き 1周+1、周回数は無制限。ただし (1) 2枚が同時に手札に要る（デッキ12枚・手札3枚で1回の引き直しで揃う確率 約4.5%）、(2) 序盤の魔力は 2〜6 でシャッフルを数回しか払えない、(3) 自陣のコマが1つ以上要る。AI に序盤から積極的に回させても（引き直し12回・魔力下限4）手番2〜7の開始時魔力は基準と同じ（4.0〜7.0）で、手番8以降にしか効かない。
