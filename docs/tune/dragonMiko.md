## 修正した不具合
- 2026-11-10: 一言居士・お一人様限りの札でスキルが無視されると、AIが同じ計画を立て直し続けて `takeTurn` の入れ子が際限なく深くなり、電気使い対巫女で33試合が Maximum call stack size exceeded（引き分け扱い）になった。sim の `aiDriver` に計画し直しの上限（12回）を付けて解消。本番は Game の監視（900ms後にチャージでパス）があるので止まらないが、AIが相手の制限を読めない点は残る（別課題）。
- クラッシュ分の引き分けが混じった順位表（巫女 36.2%・12位）は無効。修正後の 41.3%・11位が正。

- 咆哮の条件を『空きマスが少なく1本目が完成済みなら1個でも撃つ』『魔力30以上なら1個でも撃つ』に緩める（2026-11-10, 対ネクロ・対鍵師16試合）: 咆哮が連発されて（ターン終了で着手できず、自陣の建造物への⚡で自分も削れる）悪化（対ネクロ 5勝2敗9分→0勝5敗11分、絞った版も 4勝2敗10分で効果なし）。
- 龍の建造物の上限2・置き先の選び方: 上の試行5。ネクロ・陰陽師には効くが巨人・雷霆に悪化。条件付き（相手がネクロのときだけ）の採用は、相手ごとに戦略を切り替える設計になるので保留（要追試）。

## 診断（引き分けの型）
- 2026-11-10 追記: 咆哮の撃つ条件（巻き込む数・窓を塞ぐコマ・空きマス数）をどう変えても、対ネクロ・対鍵師の引き分けは減らず勝ちに変わらない。引き分けの原因は咆哮で壊せるコマではなく、別のところ（二本目の窓が自陣の建造物・ロック・凍ったマスで塞がれる／1本目が壊される／AIの着手が二本目を作る方向に偏らない）にある見込み。次は、引き分けの盤面で『二本目を作る最短の手』が何か、AIがそれを選ばない理由を直接調べる。
- 対ネクロ・対鍵師は 300手番の引き分けが多い（16試合中 13/7）。盤面が埋まり、巫女の1本目は完成済みでも、2本目の窓が自分の建造物・ライフの残った敵コマに塞がれる。ライフの残った敵コマは奪えず、壊せるのは咆哮だけ。鍵師は封鎖の断で盤面を全てロックする（巫女側の工夫では動かない）。
