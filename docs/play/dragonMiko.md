## 対局 1（vs necromancer, seed7, 先手, gears=buildMania,rubbleBase, 推奨デッキ）
再現: `node sim/duel.js new g.json --me dragonMiko --opp necromancer --seat 0 --seed 7 --gears buildMania,rubbleBase` →
`p 5` / `s prayer; p 5` / `s prayer; p 9; s prayer; p 10` / `p 12` / `s prayer; p 13`（4つ目で覚醒）/ `p 13` / `p 7` / `s prayer; p 9; s roar` / `s roar` / `h 11; p 6` / `h 3; p 5`
- 普請道楽で、自陣に建造物があると全スキルがコスト1になる。祈り→置く→祈り→置く を1手番に重ねられる（魔力2で2つ）。
- 手番6: ネクロの降霊で敵コマ5つが一度に出て、勝ち手が2か所（14, 10）。**咆哮が盤面を一掃して救った**（建造物の周囲8マスの敵コマ全て）。咆哮は防御にも強い。
- 手番8以降: 魔力が17→24と余り続ける。龍の使い道が咆哮（建造物が要る）しかなく、手札はコスト1のスキルばかり。
- 覚醒（4つ目）の時点で N=4（建造物4つが並ぶ囲みの外側が狭い型）だと龍のライフ・魔力ボーナスが小さい。

## AI 同士の膠着の観察（dragonMiko vs necromancer, 4x4）
- `node sim/probe-hoard.js dragonMiko,necromancer 20 3`: 手番開始の魔力の平均 1826、魔力12以上の手番が97.7%、決着は20試合中4。keysmith でも同様（平均1637、決着9/20）。**勝敗の前に、そもそも決着しない。**
- 200手番で打ち切った盤（seed3）: 16マスのうち、自陣の建造物（一言居士・お一人様・大岩）が5つ、自コマ9、敵コマ2で**盤面が全部埋まっている**。第1の列は完成しているが、2本目の窓は建造物（列に数えない）で潰れている。巫女が置く手が無く、毎手番ターン終了のみ。
- 龍の最後の祈り（`planDragonCore` の末尾）は「敵コマが隣にある空きマス」に建造物を置く。咆哮は魔力に余裕があれば毎回撃つが、建造物自身が⚡でライフを削られても `bind 0` のまま残り、マスを塞ぎ続ける。
- 仮説 R（空きマスが閾値以下のとき、龍は祈りで建造物を増やさない）→ LEDGER を参照。
