# 巨人 プレイメモ

## 2026-10-27
- 基準: `--rank --target giant --gears lastStand,sturdy --games 60 --seed 3` で giant 9位 43.4%。1位 poisoner 69.3%、2位 necromancer 66.2%。弱点は対陰陽師 8%・対魔法使い 24%・対ネクロ 27%。
- 局1 (`--opp poisoner --seat 0 --seed 31`): 毒使いは巨人の休み手番に毒トークンを2連で置く。手番2は自駒の13にストンプして行3のリーチを消せたが、手番4で毒が積み上がり盤上の自駒が全滅（魔力は相手10/自分3）。
- 局2 (`--opp yinYangMaster --seat 1 --seed 8`): 陰陽師AIは駒を置かず charge/markdown で魔力24まで貯め、周囲を🔑ロックして置けるマスを減らす。列カバー(yyCover)を巨人に足しても 8.7→6.7%。
- 結論: 巨人は手数が半分のため、AIの立ち回りでは魔力・手数の不足を埋められない。環境トップには数値・ルール調整（issue #97 の案: ストンプコスト、ターン飛ばし、魔力+1）が必要。

## 対ネクロマンサー (`--opp necromancer --seat 0 --seed 12 --gears lastStand,sturdy`) — 手番5で負け（最後まで指した局）
- 手番1 p5 / 手番2 p1(行0の2連続着手の脅威を、オーラで隣の0を壊して消した) / 手番3 p12(対角線3,6,9を塞ぐ) / 手番4 p7。
- **私の見落とし**: 手番4の盤で相手に即勝ち手が2つあった（行1の7、対角線0,5,15の10）。7だけ塞いで10を放置し、土壇場の防壁が発動して自駒が全消滅（ライフ値3に低下）。魔力5でストンプ(5)を撃てば両方の脅威を一度に壊せた。同じ局面で既定AIは `stompDef`(bestRescueCenter で脅威数が減るときストンプ)があるので、これは人間側のミス。AIの穴ではない。
- 手番5以降は `duel.js ai` の着手を順に打っただけで、スキルは使っていない（私の操作ミス。魔力6を残したまま負け）。相手は 整理→降霊 で行3と列0を一気に埋めて勝った。降霊の2手前（相手魔力9）から、行・列ごとに自駒を1つ置いて塞ぐ必要がある。
- 気づき: 巨人のオーラは相手のコマを壊すと墓地を増やす（ネクロの降霊の材料）。ストンプ/オーラが対ネクロで弱い一因。ストンプを撃たない案は過去に悪化（tune #18: 12.0→0.7%）なので、再発明しない。
