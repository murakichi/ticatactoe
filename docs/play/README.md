# docs/play — /play-learn の検証台帳

実際に sim で指して得た仮説と、検証した結果を**すべて**残す場所。採用・不採用・保留を問わず、試したものは必ず書く
（書かれていないものは「未試行」とみなされ、次のプレイで再発明される）。

- `LEDGER.md` — 全キャラ共通の台帳（1仮説 = 1行）。**スキルは必ず最初にこれを読む**
- `<char>.md` — キャラ別のプレイメモ（対局ログ・相手AIの癖・分岐点の盤面）
- 未試行の案は `LEDGER.md` の「未試行の候補」に書く。試したら「検証済み」へ移す

## 検証済みの行に必ず入れるもの
| 列 | 内容 |
|---|---|
| 日付/ID | 通し番号 |
| キャラ/相手 | 対象と、効くとした相手（全員か特定か） |
| 仮説 | 条件 → 取る手（AIが判定できる述語の形） |
| 根拠のプレイ | **自分で `duel.js` を指した局**の設定(seed・席・ギア・デッキ)と手番番号。再現できること。指していない行は「検証済み」にしない |
| 測定 | コマンド・games・seed・基準値 → 候補値（差と標準誤差） |
| 判断 | 採用 / 不採用 / 保留(理由) |
| 反映先 | フラグ名、ファイル、本番(AIPlayer.ts)ミラー済みか |
